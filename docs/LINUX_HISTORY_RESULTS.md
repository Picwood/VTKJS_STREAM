# Linux history-result browsing and export

Implemented and accepted on 2026-10-29. This closes the original PrePoMax
history-result catalog, aligned table, plot and delimited-export slice for
portable result projects. CAD repair remains outside project scope.

## Workflow

GTK **History results…**, the viewer companion and `prepomax-linux-cli` share
`ProjectHistoryResults`. Result PMAs containing raw CalculiX DAT are parsed by
the production `DatFileReader`; projects containing persisted binary histories
use the same `FeResults` representation. The catalog lists result set, field,
component, entries, sample count and time range.

Selecting a component opens an aligned table generated by the production
`FeResults.GetHistoryOutputData` path. The GTK dialog draws up to twelve entry
curves against the aligned time column and keeps the full table available for
numeric inspection. CSV export delegates to the production
`ResultHistoryOutputWriter`, supports one selected result set or all sets, and
offers comma, semicolon and tab delimiters.

```text
prepomax-linux-cli history-results RESULT.pma
prepomax-linux-cli history-series RESULT.pma SET FIELD COMPONENT
prepomax-linux-cli export-history RESULT.pma NEW_RESULTS.csv [--delimiter comma|semicolon|tab]
```

Exports are staged in the destination directory, committed atomically and
refuse to overwrite an existing file. Parsing rejects mismatched or non-finite
samples. A project is limited to 100,000 series, 100,000 entries per series,
5,000,000 samples and 5,000,000 aligned table/export cells. The viewer companion
serializes these operations with native jobs and does not expose temporary DAT
files.

## Acceptance

- The portable Release build has zero warnings/errors and the full suite passes
  **5,543 checks**, including 22 new catalog, alignment, delimiter, overwrite,
  invalid-selection, empty-result and staging checks.
- Native CalculiX 2.23 produces a two-step DAT result. CLI catalog and table
  discover finite U1 samples, semicolon CSV export succeeds, and the source PMA
  remains byte-identical.
- GTK X11 software WebGL opens the catalog and aligned table, renders the Cairo
  line plot, exports the selected set and closes the renderer listener.
- Fresh Ubuntu 24.04 installs the declared `python3-gi-cairo` dependency, solves
  the authored project with distribution CalculiX 2.21, and passes catalog,
  table and semicolon export through the installed CLI. Upgrade from
  `0.1.5~preview+history-results.1` to `.2` and purge also pass.
